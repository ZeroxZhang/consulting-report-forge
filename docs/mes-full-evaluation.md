## 与旧版 B 的具体差异

比较对象为用户提供的2026中国MES旧稿，共16页；原始数据来自同项目的市场数据.md。已读取旧稿全部标题链，并重点查看旧稿实际第5、6、7、9、10、14页。下表是针对具体页的比较，不是全册盲评得分。

| 问题 | 旧稿表现 | 新稿处理 |
|---|---|---|
| 地区比较 | 第5页用全国基准线和差额注释压缩表达，便于判断偏离 | 第6页并列规模与强度，明确分母是全部规上制造企业，不等于客户客单价；旧稿基准注释仍值得保留学习 |
| 集中度 | 第6页将列示七家称为头部七家，并推断集中度 | 第8页只判断固定七家份额近似持平，不把未知排名当CR7 |
| 人均创收 | 第7页标题直接使用效率解释 | 第11页区分人均创收和顾问人数分母，不替代工时、成本或利润效率 |
| 成本行为 | 第9页从构成推断三项随项目数线性增长、云许可可摊薄 | 第12页保留构成，明确判断规模效应还缺固定/变动成本及项目数据 |
| 等待时间 | 第10页把5.8周嵌套在现场实施9.1周中 | 第14页使用独立参考条；材料未定义包含关系。第15页另列明确假设的敏感性矩阵 |
| 观察与原因 | 第14页观察阈值与原因结论连接过强 | 第16–18页转为待验证问题、备选路径与继续/停止条件，不把阈值当因果证明 |

新版主要优势是计算和推理边界更可检查，行动建议更明确。代价是篇幅由16页增至20页，标题与底部判断有部分重复，分析压缩仍有提升空间。旧稿已有子弹图、发散条、气泡图、华夫图等表达，不能因为新版有更多页面就认定图表更丰富或叙事更强。

## 验证结果与实际返工

20页HTML与20页PDF由作者及独立审查实例实际查看；最终工程验收0错误、7条诊断告警逐项处置。告警主要涉及来源页留白、来源真实性和重复结构，保留说明见审查记录。来源九条定位均来自同一整理稿，未冒充九个独立来源；没有逐项外部核验。

完成正式打包、同版PDF内嵌和不可变审查快照。全部 `npm test` 通过。真实案例发现小数显示中点受二进制格式化影响，统一改为十进制halfExpand显示，并补正负中点及负零回归；内容合同现23项检查通过。计算保留未舍入值。

本轮跑了2次代表页预览、1次整稿冒烟、3次整稿完整验收；另有一次书挡边界声明缺失导致装配拒绝。修正还包括代表页标题间距、份额标签、标题数字绑定和来源期间。检查通过不意味着完全无需返工。

## 能说明什么、还不能说明什么

这是同材料重做，未找到旧稿原始提示词，模型与执行过程也未固定；因此不是严格A/B实验，不能将所有差异归因于技能。执行记录只计首个计算脚本落盘至完成打包的观察窗口，不含前期资料寻找，没有旧稿可比耗时，也没有token或费用数据；不报告提速比例。

后续若要决定正式替换，应固定任务、输入与模型，在另一个题材上复用本流程，再比较叙事压缩、证据准确度、图形适配和实际用时。开发分支与本地验证产物保留，方便追溯本次结果。
