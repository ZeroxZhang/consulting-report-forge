# 报告技能升级：设计与验收

基线：`1d54049`；实验分支：`codex/report-upgrade`。升级最初在独立分支开发和验收；用户确认完整样稿后，授权合并主分支并推送。

## 要解决的问题

1. 业务证据、标题、页面声明与成稿分别维护，文字一致性校验不能发现推断越界，局部修改容易遗漏。
2. 固定版式与形式数量配额不能代表好报告；历史优秀版式需要自由区域与通篇节奏。
3. 复制审查文件无法冻结证据。原 HTML、PDF 或图片变化后，继承记录不能证明原先审过什么。
4. 专家数量不是分析质量。分析缺口与最终主张必须有明确负责人，同时独立审查须来自实际不同实例。

## 实施边界

- 保留 D 的静态 HTML、SVG、字体与 PDF 内核；以 B 的分析方法和 C 的职责分工补充创作层。
- 新蓝图 schemaVersion 2 为内容权威，编译生成 pages version 4。关键主张、口径、身份、限制、来源、计算和结论标题通过可见 DOM 绑定进入成稿；装配和 QA 各自验证。
- 旧 schemaVersion 1 与 pages version 1–3 继续可读，旧规则不在历史报告上悄然改变。
- 目录布局与 custom 区域均合法；新稿的重复、类型数量及留白比例作为审查诊断。结构错配、溢出、不可读与瀑布算术错误继续拦截。
- 接受完成的审查及其全部证据生成不可变快照。局部复验只能生成待完成草稿，不能替人填写 PASS。
- 主笔归口，专家按分析缺口启用。先验证代表页，再扩展整册，局部问题局部修复。

## 验收证据

- 原有单元、合同与浏览器回归保持通过。
- 新增跨文件内容篡改、预测身份、计算循环/零除、自由布局、配额降级、审查快照迁移与复用失效测试。
- 用定量经营、多源策略、稀疏定性及定稿重排任务验证流程；生成实际 HTML/PDF 并检视代表页面。
- 对用户给出的 B/D 历史材料做针对性复现：保留值得学习的分析与布局；阻止成本构成推断成本行为、观察阈值冒充因果、预测伪装历史及不闭合瀑布。
- 测试结果区分自动检查、真实独立 Agent 执行和人工式图像审查。没有同题同模型的对照测量，不宣称节省具体比例或分钟数。

## 本轮不会自动证明的事项

DOM 绑定能证明声明的内容进入成稿，不能穷尽未登记文字的全部商业逻辑或证明图形几何真实。来源登记不是外部事实核验；审查仍须看原材料、推理和图像。自由绘制的图形须如实声明语义，不能把算术图登记成普通装饰规避检查。
