## 使用

```sh
node scripts/report_status.cjs status /任务/task.json
node scripts/report_status.cjs next /任务/task.json
node scripts/report_status.cjs status /任务/task.json \
  --audit /任务/renders/audit.json --review /任务/author.json
```

状态从现有文件推导。发现待办返回 `ACTION_REQUIRED` 和退出码1；指定记录均有效返回 `CHECKED`，不代表完成聚合、打包或人类审查。未传入的 audit/review 明确显示未检查。任务无效、版本不支持、输入损坏或丢失均返回定位信息；已有预览稿不会被当成正式成果。审查记录和审计分别按各自目录解析，任务引用按 task 目录解析，分析附件按蓝图目录解析。

字体措辞变化仅出现在新运行结果，历史 audit、快照与签名不原地更新。重新执行 QA 产生新的 audit 时，照常要求绑定新的审查；没有自动继承通过结论。
