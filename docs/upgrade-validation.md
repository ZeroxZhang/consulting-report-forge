# 1.3.0：升级与验证记录

验证日期：2026-09-22（北京时间）。基线 `1d54049`，实验分支 `codex/report-upgrade`。升级开发与验收均在独立 worktree 完成；用户确认完整样稿后，授权合并主分支并推送。

## 这轮完成了什么

沿用 D 的静态 HTML/SVG/PDF 与字体内核，将 B 的业务分析方法、C 的主笔归口和按需专家机制纳入流程。保留 D 擅长的自定义布局，不用图型数量、布局数量或空白面积替代实际阅读判断。详细设计见 [upgrade-design](upgrade-design.md)。

| 改动 | 对报告制作的作用 |
|---|---|
| 方法路由、证据边界与标题链 | 先回答业务问题，再选框架和页面；不从成本占比直接推断成本行为，不把观察阈值当因果，不把定性小样本当市场发生率。 |
| 主笔归口、按需专家与真实独立审查 | 专家解决具体缺口，主笔统一判断；不默认启动所有角色，不拼接各人的摘要。 |
| 蓝图 v2 → 页面合同 v4 | 标题、主张、指标、身份、来源和限定从同一内容源进入页面；装配与最终 QA 分别核对。 |
| 计算依赖与可见文字绑定 | 数值改变后，派生比例及使用插值的文字同步变化；拒绝缺引用、循环、零除、身份升级、关键文字隐藏和旧计划冒充新稿。 |
| 自定义阅读区域与诊断式审查 | 允许合理重复和有目的的留白；保留溢出、可读性、结构和算术检查。旧 v1–v3 合同保持原行为。 |
| 瀑布输入与实际图形双重核对 | 从原始输入派生桥接结果，同时核对实际 SVG 增减项；仅总量对账通过还不够。 |
| 审查快照、复用草稿与历史问题追踪 | 冻结实际 HTML/PDF/图像及审查链；未变页可沿用同一审查者的真实覆盖，变化页和整体判断仍需复核，工具不代填 PASS。 |

本记录中的 `renders/` 路径为本地归档，不随仓库分发；可复现的测试与合成任务保留在仓库。完整20页报告的补充结果见[MES验证记录](mes-full-evaluation.md)。

## 实际新实例制作测试

使用未继承本次诊断和实现讨论的独立制作实例，按新版 SKILL 读取 [四个原始合成任务](../evals/tasks.json)，实际制作六页正文，再由未参与样稿制作的主实例复核。不是把测试脚本生成的页面当作 Agent 执行成果。

| 原始任务 | 实际观察到的行为 |
|---|---|
| 经营分析，2 页 | 计算等待占比，区分等待规模与可改善量；未从成本构成推导规模经济或利润。 |
| 多源策略，2 页 | 拒绝将 100、18、15、5 强行连成瀑布；用有身份标注的九格情景区分基数、费率、收费额与收入确认。 |
| 稀疏定性，1 页 | 保留六名非随机受访者的样本边界，用计数表达，没有外推总体发生率。 |
| 已确认内容重排，1 页 | 保留原文及限定，用三条阅读带组织内容，保留适当留白，没有为填满页面增加事实。 |

作者和独立复核者实际查看了最终六页 HTML 与六页 PDF 图像；工程验收为 0 errors、7 warnings。七项告警涉及有意缩放、重复结构、表达种类与稀疏页留白，均逐项给出接受依据。第一次看图后曾修正第 2 页条形图与分隔线间距，随后重新导出并复看。

实际执行也暴露出摩擦：最初模板缺失已补齐；作者误用预览参数和自定义骨架后修正。六页测试先写齐片段，再预览代表页，不把这次结果说成已经证明长篇“代表页收敛后批量扩展”的效率。完整行为、返工与计时范围见 `renders/forward-eval/execution-log.json`（execution-log.json，本地归档）。

## 实际单页修订与复用

先将完成双角色、双媒介审查的原稿保存为 v1 快照，再模拟只将第 1 页等待时长从 5.8 周修订为 6.0 周。重新编译和导出后：

- 第 1 页变为 65.9%（6.0÷9.1）和 33.0%（6.0÷18.2），图形、数值及正文同步更新；HTML/PDF 两种媒介由作者和独立复核者重新看图。
- 第 2–6 页的内容、页级样式、公共依赖与两种媒介图像摘要保持一致，五页审查覆盖可复用。
- 全篇判断及现存告警仍重新审查，没有把“eligible”当作新的审查结论。

实际失效范围见 `renders/forward-eval/reuse-v2/reuse-plan.json`（reuse-plan.json，本地归档）。v1/v2 快照、原始证据、作者记录、独立记录和聚合记录均保留在 `renders/forward-eval/`。快照属于摘要校验的归档，不是物理防篡改存储。

## 历史成稿兼容性

用户提供的 B、D 历史样稿保持只读。新 QA 对 B 的同内容源稿 16 页与 D 的 23 页运行 smoke，均 0 errors；B 有 4 warnings，D 有 89 warnings，多数为旧稿小字号诊断。B 测试使用交付目录旁的同内容源稿及其页面声明，不把打包后的交付 HTML 当成重新完整验收。

这只是历史渲染和合同兼容验证，没有将旧稿的全部业务推理或交付重新判为通过。

## 仍未证明的事项

本轮完成工程回归、四类小规模制作验证、双媒介实际审查和单页修改复用。没有做同题、同材料、同模型的 B/D/新版多次盲评，因此不能声称新版总体优于所有旧版，也不能承诺节省某个比例的时间。

内容绑定验证“声明的内容进入成稿”，不替代外部事实核验、商业方法选择或任意 SVG 几何含义的判断。大规模长报告、外部研究耗时及不同模型上的稳定性，需要后续真实项目继续验证。

查看最终合成验证样稿：`renders/forward-eval/delivery-v2/新版技能验证样稿.html`（HTML，本地归档） · `renders/forward-eval/delivery-v2/新版技能验证样稿.pdf`（PDF，本地归档）。它用于检查技能表现，不是可直接引用的市场研究结论。
