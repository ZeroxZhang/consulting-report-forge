## 先定深度，再选方法

- **分析**：原始数据或访谈需要诊断、选择或建议。列出关键问题、竞争解释、要找的证据，优先做可能改变结论的分析。
- **探索**：问题尚不清楚。先检查范围、异常、差异与机制，再形成有限判断；不预设推荐结论。
- **编辑**：已确认内容的重组和制作。做必要算术、口径与状态核对，不因一处局部疑点重做全套研究；发现实质冲突则返回受影响判断。

选方法的顺序：**读者问题 → 业务机制 → 数据口径 → 方法前提 → 最简单够用的计算或比较 → 反证与边界**。没有合适命名框架时使用透明的自定义分析，不为套模型改变问题。

## 问题到方法的路由

| 业务问题 | 方法链与实际产出 | 必须成立的前提；不能推出什么 |
|---|---|---|
| 收入或利润为何变化 | 统一期间与业务范围 → 盈利驱动树 → 量价组合或会计贡献分解 → 核对起点、变化、终点 → 检验经营解释 | 量价分解需要同粒度且数量可加；固定分解顺序并单列新品、退出项与残差。贡献说明变化来自哪个算术分项，不证明涨价导致销量变化。实现与残差规则见[瀑布数据合同](waterfall-bridge.md)。 |
| 增长是否赚钱、扩张条件是什么 | 每客户/订单/门店收入 → 增量成本与贡献 → 留存/回本 → 容量与现金约束 | 分清收入、利润、现金及固定/变动成本。成本占比不能证明成本随项目数线性增长或可摊薄；需要成本行为数据。单位贡献≤0时不报正盈亏平衡量；缺留存数据不套终身价值公式。 |
| 规模、强度与效率是否一致 | 同口径总量与排序 → 每企业/员工/资本归一 → 比较排名差异 → 检查结构与服务范围 | 分母是全部企业还是实际客户、全体员工还是顾问必须明确。地区户均总支出不等于客户客单价或渗透率；人均收入不等于利润率或交付效率。横截面排序差异不证明规模导致效率升降。 |
| 哪个行业/细分值得进入 | 定义市场边界 → 自上而下与自下而上规模核对 → 五力/价值链与利润池 → 可行进入方式 → 单位经济、资源及退出条件 | 存量、年度支出与上下游交易不重复相加；可获得市场不能由总市场乘随意份额得到。行业增长、规模或主观评分不能直接支持进入建议；缺必要投入数据时给条件比较和取证顺序。 |
| 多份访谈或案例说明什么 | 定位原话与样本 → 按主体、动作、条件编码 → 比较共同机制与反例 → 检验替代解释 | 保留样本选择、编码单位与分母；重复转引不算独立证据。访谈频次不等于市场比例，少量成功案例不证明必要或充分条件；流程先后与参与方分工不等于已识别因果。 |
| 不确定情景下投多少、何时调整 | 现状基准与备选 → 增量现金流 → 情景/敏感性 → 改变选择的条件 → 验证与停止安排 | 输入、假设、公式、结果分开；排除沉没成本并计入蚕食、营运资金和相关变量。预测不冒充实际，目标不倒填成预测；无依据不给情景概率。作者阈值是复查触发器，不自动识别原因；利润不能直接当现金回收。 |

跨任务通用检查：期间、单位、覆盖对象、分母是否一致；缺失是否被误填为0；是否只看总量而漏掉基数、分布或异常；是否将实际、估计、预测、目标混为一条序列。只有汇总值时不能恢复原始分布，短序列不足以确立季节性或稳定外推关系。

## 让分析可以交接

每个会改变判断的结果要回答六件事：**证明什么、输入在哪里、怎么算、依赖什么前提、还有什么解释、什么证据会改变答案**。沿用[证据身份记录](evidence-ledger.md)保存来源性质、公式或脚本定位、推论与限制；只核对用户材料不等于外部核验。

计算使用实际输入与可复算脚本/工作表，注明输入版本、单位、分母和舍入方式；图、标题和注释读取同一结果。定性分析保留原文定位、比较维度与推理依据。不要只交分析计划、框架名称或无法复算的数字。

证据不够时，先补同口径基准、驱动分解、反例或执行条件；仍不足就收窄判断或合页。不要为填密度引入无关研究。纯假设模型可以展示变量关系，但必须显式标注，不能生成“合理值”后冒充基准预测。

## 从计算到页面的最小例子

**合成示例**：某市场从100增至120，两板块分别贡献+16与+4；前者贡献80%的增量，但这些数不能证明增长由某项政策造成。主展品表现增量闭合，互补内容解释基数与口径；若讨论政策原因，另补识别依据或保留为假设。

完成标志：关键结果能复算；结论强度不超过证据；替代解释与未知有去向；后续页面要表达的关系已经明确。主线组织见[咨询叙事](consulting-storyline.md)，需要专业分工或独立质疑时见[协作](collaboration.md)。
