# 咨询级单页系统

> 一页不是一个容器；它是从**结论 → 主证据 → 解释/限制 → 来源**的可扫读论证。

## 页面骨架与视觉预算

普通正文页的阅读顺序固定为：**结论型标题 → 主展品 → 支持证据/关键限定 → 含义或行动 → 来源**。版式可以不对称，但顺序不能依赖讲解者猜测。

| 区域 | 应承担的责任 | 常见失误 |
|---|---|---|
| 标题区 | 用一句可证伪判断建立阅读任务 | 写“市场分析”“AI趋势”等名词标题 |
| 主展品 | 第一眼证明标题中的核心关系 | 小图居中、无共同量尺、只做装饰 |
| 支持证据 | 给基准、分母、异常、条件、反例或时间维度 | 重复主图数字、堆文案卡 |
| 含义区 | 将发现转换为取舍、风险或行动 | 复述标题、堆“因此建议” |
| 来源区 | 给可核查出处和关键限定 | 微字、截断、与页码冲突 |

### 密度不是拥挤

| 密度 | 合理构成 | 适用页面 | 不可接受的替代 |
|---|---|---|---|
| `dense` | 主图 + 2个以上不同证据职责 + 明确含义/限制 | 核心诊断、路径选择、复杂比较 | 3个等权卡片、碎片化数字或微字表格 |
| `balanced` | 主图 + 一个有不同职责的支持单元 | 默认分析、机制、研究结论 | 只有一张小图，剩余空间空置 |
| `sparse` | 一个关键证据/判断 + 经解释的停顿 | 章节转折、单一重大结论 | 把缺证据或没做完包装成极简 |

### 留白纪律

留白只可承担四种职责：**分组、聚焦、比较间隙、来源安全区**。它不能替代信息密度。若正文有约五分之一以上的无解释空洞，按此顺序返工：补比较基准/分母/反例/机制/行动含义 → 重组阅读路径 → 收紧或改变主辅比例 → 最后才调字号和间距。

## 高密度但可读的布局模式

| 模式 | 结构 | 最适合证明 | 避免方式 |
|---|---|---|---|
| **主图 + 证据侧栏** | 65–75%主图，25–35%基准/限制/小表 | 比较、趋势、贡献 | 将侧栏变成三张等权数字卡 |
| **总览 + 局部放大** | 先给全局结构，再放大决定判断的子集 | 分布、客户分层、区域差异 | 同一数据画两张相同图 |
| **机制 + 量化锚点** | 流程/机制居中，旁侧放关键规模、阈值、控制点 | 因果假设、运营流程、产品链路 | 用箭头代替证据，或将节点画成等权因果 |
| **结论矩阵 + 行动门槛** | 上方权衡/优先级，底部所有者、指标、停止条件 | 推荐、路径选择、治理 | 九宫格泛化评分且没有评分锚点 |
| **比较表 + 关键标注** | 表可查值，贴近对象标出决定差异 | 多维产品、规则、财务口径 | 让每个单元格塞长段落 |
| **时间线 + 分叉情景** | 基准事实与条件性路径分开 | 政策、路线图、转型 | 把未知日期画成确定承诺 |

默认不要使用相同宽度的三栏卡片、金字塔结论、装饰性大引号、无语义的图标阵列、整页背景纹理、彩色边条或用颜色代替标签。

## 图形与信息图严谨性

1. **比较**：使用共同基线、排序规则和直接标签；不要让颜色或面积独自承担大小比较。
2. **趋势**：区分实际、预测、目标、缺失；预测在视觉和文字上都应有边界。
3. **构成**：仅在类别互斥且可加时使用份额表达；否则使用并列基准或嵌套关系。
4. **贡献**：瀑布、桥接或贡献排序必须能对账；描述性分解不可称为因果归因。
5. **流程/机制**：箭头写明流向、条件或责任；等宽节点和连接线不能暗示同等规模、时长或因果。
6. **矩阵**：每条轴、每个评分或热力色必须有明确业务定义；没有可靠评分就改为定性分类并明示。
7. **表格**：单位、期间、对齐、缺失含义、总计与高亮规则必须可解释；关键列保持少，复杂细节放附录。

## 排印、色彩与可访问性

- 每页最多使用一个标题级、两个正文级、一个辅助注释级；同一语义角色用一致字号、字重和色彩。
- 默认使用明亮底色 + 深色正文；强调色仅用于分组、状态或被直接标签补足的重点。不得出现浅色背景上的浅色文字，或深色背景上的深色文字。
- 不把决定判断的信息放进小于可读阈值的脚注；来源可以紧凑，但不得遮挡或截断。
- 表格、矩阵和图表应允许读者在灰度、投影或打印中区分状态：采用文字、线型、形状或直接标签做冗余编码。
- 同一页中对象的边界、文字基线、比较轨道和数字小数点应对齐；用真实绘图区而不是外框检查。

## 一页制作顺序

1. 先写标题、`proves` 和主展品的最小数据需求。
2. 增加一个能限制、比较或推进主结论的第二证据单元。
3. 仅当需要把判断转为取舍/行动时增加 `implication` 单元。
4. 选择布局模式，标出阅读路径、来源安全区与留白用途。
5. 在实际16:9预览中检查视觉重心；如果主要内容只占上半页，先回到第2步，而不是放大图或添加空框。
