# 表达选型：从关系到证据

> 先问“读者必须看出什么关系”，再问“用什么图”。图型是证据的形状，不是装饰。

## 快速选择

| 关系 | 常用表达 | 先检查什么 | 不要这样做 |
|---|---|---|---|
| 对象比较、排名 | 水平条、点图、哑铃图、坡度图、帕累托 | 共同基线、固有顺序、Top N 是否遗漏重要对象 | 用排序破坏时间或流程顺序 |
| 时间趋势、周期 | 折线、阶梯线、柱线、日历热力、小多图 | 连续/离散期间、缺失/零/预测、系列遮挡 | 用平滑线伪造连续变化 |
| 构成、占比、层级 | 堆积条、100% 堆积、华夫、树图、旭日 | 部分是否互斥可加、整体定义、类别规模 | 对不可相加的数据画份额图 |
| 分布、离散、异常 | 直方、箱线、小提琴、蜂群、ECDF | 样本量、分箱或估计规则、异常定义 | 只报均值而掩盖决定判断的分布 |
| 相关、多变量、群组 | 散点、气泡、热力矩阵、四象限、分面 | 变量类型、阈值依据、相关不等于因果 | 用视觉团簇宣称统计显著群体 |
| 目标、绩效、状态 | KPI + 趋势、子弹图、目标差异条、记分卡 | 单位、期间、目标基准、正负业务语义 | 给任意数值套 0–100% 仪表盘 |
| 增减、贡献、桥接 | 瀑布、桥接、差异条、贡献排序 | 起点/终点能否对账、分解方法、残差 | 将描述性拆分说成因果归因 |
| 流程、流量、转化 | 漏斗、桑基、转移矩阵、队列图、泳道 | 阶段口径、守恒边界、真实顺序 | 用等宽箭头伪装定量流量 |
| 网络、生态、关系 | 节点连线、二部图、邻接矩阵、弦图 | 节点/边/箭头语义、密度、布局限制 | 将力导向距离当业务距离 |
| 地理、位置 | 分级设色、比例符号、流向、网格 | 地理是否解释问题、边界版本、分母 | 只为地区名称而使用地图 |
| 区间、不确定性 | 区间点、置信带、森林、龙卷风 | 区间含义与计算依据、模型假设 | 编造置信区间或预测带 |
| 项目、时间、定性结构 | 甘特、路线图、责任矩阵、逻辑树、架构图 | 日期、依赖、责任、定性/定量身份 | 把无证据的层级画成“金字塔结论” |
| 精确查值、互补证据 | 明细表、热力表、图 + 表、总览 + 局部 | 读者是否需逐格核对、两个展品是否分工 | 用重复图表填页面 |

## 选择程序

1. 写下页面主张及它要求读者看出的关系。
2. 排除数据不支持、口径不可比、编码误导、静态不可读或依赖不可用的方案。
3. 在剩余候选中比较：决策任务匹配度、比较精度、重点识别、信息容量、学习成本和制作成本。
4. 选择主表达；只有存在实质取舍时，记录一个备选及其胜出条件。
5. 检查标题、图例、标签、尺度、注释和来源是否共同证明同一主张。

## 静态媒介编码底线

- 用共同位置或长度做精确比较；柱、条默认以零为基线。非零折线起点必须显著说明。
- 将实际、预测、缺失、零值、百分比和百分点分开编码，并直接写出单位、期间和基准。
- 气泡按**面积**而非半径映射数值；双轴不制造相关；雷达图仅用于少量且尺度可比的维度。
- 多系列遮挡时改小多图、分面或总览加局部，而不是不断加颜色。
- 桑基、瀑布与份额图先验证流量、总量和端点；不隐藏残差、损耗、补充或不可解释部分。
- 地图只在地理位置参与解释时使用；纯地区比较通常先考虑排序条形图。

## 将文字翻译成视觉论证

将文本中的主体、动作、条件、依赖、反馈、交付物和反例展开为结构。箭头必须标明作用、交接、包含、前置条件或证据状态；箭头本身不证明因果。

构思时为每页指定一个主视觉，再分配互补说明。可使用不对称版式、嵌入式注释、总览 + 细节或图表 + 机制；不要默认左图右字。若图型重复到第三页或连续三页相同，写明为什么它仍是最优表达；写不出来时，回到材料而不是只换皮肤。
