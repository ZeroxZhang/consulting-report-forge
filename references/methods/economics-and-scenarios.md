# 经济模型、情景与敏感性

适用：单位利润、定价、投资、进入方式比较。缺内部数据时做有边界的条件关系，不生成假精确基准预测。

## 输入与口径

同期间收入/销量/价格、成本行为、固定成本、增量投入、营运资金、税费、容量、留存、折现率依据。金额要区分含税/不含税、现金/损益、一次性/持续性；成本分摊与可避免成本分开。

## 执行

- 收入 = 数量 × 实际净价；贡献 = 收入 − 对应可变/增量成本；单位贡献非正不能报告正的盈亏平衡销量。
- 量价分解固定顺序。例如 ΔR = (P1−P0)Q0 + (Q1−Q0)P1；它含交叉项在后项。多产品先对齐 SKU、数量单位与组合口径；新增/退出单列。不要把顺序不同的分解公式拼接。与总账闭合，残差如实解释。
- 比较投资用增量现金流，计入蚕食、营运资金、启动/退出成本；不把利润直接当现金。沉没成本不决定未来增量选择。残值、折现率、税率依据缺失就登记缺口。
- 情景覆盖相关变量的联合变化；敏感性先找会翻转选择的变量，再做单变量/双变量或区间。不给无依据的概率；情景不是置信区间。
- LTV 只有留存、毛利和 cohort 口径支持时才算；短期便利估计不能隐含无限持续。回本期用实际贡献现金与获取投入，注明右删失客户。

复杂模型在外部脚本/工作表执行：记录输入、代码、输出摘要及 run，用结果 JSON pointer 映射选中指标；代码正确和模型识别有效是两回事。

## 输出、反证与解释

驱动桥、单位经济、备选现金差异、临界条件与待验证假设。至少核对合计闭合、量纲、负分母/零分母、相关情景和压力边界。会计贡献不能证明因果；边际有效不意味着容量无限。若推荐在小幅合理假设变化下翻转，给条件选择与取证优先级。
