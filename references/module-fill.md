# 正文模块填充协议

在模块规划、代表页预览和最终视觉审查时读取。固定要求 `module-fill` 是：**模块填充：必须逐一检查正文每页的每个模块及每一栏，尤其是文字模块；没有明确设计功能的大块留白必须修复，裁切和溢出必须消除。** 每个空白区域都必须有可说明的设计功能；没有功能的空白是缺陷。

## 范围与判定口径

范围是每个正文页的固定尺寸模块、卡片、面板及内部各栏；透明文字区也要检查。先检查整个模块，再分别检查每一栏；左右空白与上下空白执行相同的原则。声明为封面、封底、章节页或参考资料页（`cover/back-cover/divider/references`）不混入正文填充统计，仍接受一般视觉、溢出与来源检查。`sparse`、`open` 或“金句版式”标签本身不豁免检查。

- **内容区**：模块内边距以内可安放内容的区域；模块标题、单位和固定底部元素各有真实占位。必要时同时检查标题以下的正文子区，不能让标题或底部来源掩盖中部空洞。
- **组**：共同表达一个意思的元素，例如小标题及正文。组内间距小于组间距。
- **档位**：当前设计系统允许的字号、行高与间距值。优先沿用已选母版和组件；没有可用档位时先明确设计值，不临场无限微调。
- **弹性元素**：能在保持语义、比例、可读性与比较量尺的条件下调整尺寸的图片、图表或示意图。背景框、空占位和文字容器不是弹性内容。
- **预留空白**：为分组、聚焦、比较间隙、节奏停顿或来源安全区明确保留的区域。须逐区域记录位置、功能及模板/阅读任务依据；不能事后把所有空洞都命名为预留。

不要混用两种度量：

| 度量 | 如何得到 | 可以支持的判断 |
|---|---|---|
| `baselineFillRatio`：默认样式填充率 | 同一内容在当前设计系统默认字号、默认间距下实际排版，内容所需高度 ÷ 对应内容区高度；记录默认样式、区尺寸、内容高度及计算依据 | 规划容量和选择初始修复级别。没有真实基线时写未测量，不能从成稿容器高度反推 |
| 成稿占用/投影与空白带 | 基于当前成稿的实际文字行框、可见图形及区域边界测量；明确轴向和媒介 | 定位顶部堆积、底部/侧边空洞、空栏及裁切风险。结果不是默认样式填充率，也不是视觉评分 |

85%/60% 是默认样式基线的诊断阈值；达到 85% 不自动通过，低于 85% 也不能直接否定有功能的空白。图表/SVG 的外框占满，不能证明内部绘图区已经充分展开；最终都要查看真实画面。

## P — 排版前预防

| ID | 必须做的事 |
|---|---|
| P1 | 逐模块、逐栏统计真实内容量，选择既放得下、又与内容形状匹配的布局。对普通连续文字区，在默认样式下以 85% 为容量选型参考；明显不足时优先换组织方式或布局。保留低填充区域须说明阅读功能，不能填造内容达标。 |
| P2 | 有图片、图表或示意图时，选择一个适合吸收余量的主要弹性元素，写明它的最小可读尺寸、比例及量尺约束；没有适合元素就重排，不添加装饰占位。 |
| P3 | 固定模块标题、模板锚点与底部来源/注释区域；底部元素按所选模板落到底边安全区。必须贴近主张的关键限定仍贴近被解释对象，不能为对齐把它移远。 |
| P4 | 同排且功能相同、默认样式可比的模块，核对内容分配是否失衡；有真实基线时以填充率差 ≤15 个百分点为诊断参考。比较不同职责的图、表、文字时不硬套此差值。 |

`module-fill-plan` 覆盖正文模块、内部栏、内容量、组织候选及取舍、弹性元素与预留空白。规划依据引用权威蓝图与真实材料；不是提前签署最终画面的 PASS。

## D — 逐区域检测

| ID | 检查与记录 |
|---|---|
| D1 | 找出上下、左右最大的连续空白带。纵向检查跨区域全宽的带，横向检查跨区域全高的带；逐栏再次检查。超出该轴允许最大组间距的带必须定位并判断功能，无功能则为缺陷。 |
| D2 | 把内容区从上到下分三带、从左到右分三带，检查是否有整带无内容。命中必须解释具体区域的阅读功能；不能只凭比例判 PASS 或硬填空白。 |
| D3 | 检查文字行、图片、图形标注是否被裁切、越界、遮挡或进入固定安全区；不能只看父容器边界。预留空白不豁免裁切和溢出。 |
| D4 | 空白诊断只排除已经记录位置、功能及依据的预留区域；其余区域继续 D1–D3。截图仍保留完整区域，审查者判断该预留是否成立。 |
| D5 | 逐区域记录页、模块/栏标识、媒介、规则 ID、度量类型与结果、空白带位置（上/中/下/左/中/右）、缺陷或保留依据、修复及复检结果；未测量不得写伪精确数。 |

排查两类漏检：父容器高大但实际文字只在顶部；一栏内容很多而另一栏几乎为空。不能用全页或父模块的平均值覆盖子栏。同行标题对齐、来源贴底也不能证明中间内容足够。

自动探针提供的是检查起点。审查者必须对照实际 HTML/PDF 补齐未标记的文字区、嵌套面板和子栏，确认每个正文模块及每一栏都留下记录。图形内部留白、图片焦点、阅读用途不能仅靠 DOM 度量判断。

制作自定义结构时，在模块上加 `data-fill-region`、内部每栏加 `data-fill-column`，让检查对象可定位。已有 `[data-module]`、`[data-panel-id]`、常见卡片与布局子项会被识别；属性值不作为唯一身份，探针按实际 DOM 路径枚举。预留区域用 `data-fill-reserve="具体设计用途"` 标记。用当前设计系统的最大组间距填写 `data-fill-max-gap="逻辑像素数"`，可放在模块或正文祖先上；缺省 48px 仅为诊断参考，不证明符合所选设计档位。预留标记不会删除检测候选，仍须在审查中逐项判断。

`preview_page.cjs --json` 返回屏幕实测清单；正式 QA 在 `audit.rows[].moduleFill` 与 `printModuleFill` 分别记录屏幕和打印测量。`review-pack` 将它们整理成待审区域，打印测量须对照实际 PDF 画面。

## F — 有界修复

先判断是局部排印余量，还是内容与布局不匹配。具备真实基线时：≥85% 从 L1 开始，60%–85% 从 L2 开始，<60% 从 L3 开始。没有基线时按实际缺陷选择并说明依据：局部小余量用 L1/L2；大片空洞、空栏或宽高形状不匹配直接 L3，不先把字体和间距膨胀到上限。

每执行一步都对本模块及同排模块重新检查 D1–D3；无未解决缺陷才停止。L3、L4 每轮各最多执行一次，执行后重新测量适用的基线并选择起始级；已执行过的级别进入下一级。可用步骤耗尽仍有缺陷时，记录问题并交主 Agent 调整整体组织，不无限循环、不把未解决问题标为完成。

| 级别 | 按序尝试的修复 | 边界 |
|---|---|---|
| L1 间距 | 同级组间距同时增加一档，逐步复检，达到上限后停止；标题下仅一个组且没有其他锚定关系时，可在剩余内容区垂直居中 | 不把全部余量加到某一个间距；始终组内间距小于组间距。垂直居中后仍要检查两侧空白功能 |
| L2 尺寸 | 先放大合适的弹性图形；再调整主元素；再尝试正文增大一档；最后调整行高 | 每一步受已选设计系统、层级和量尺约束。不得让正文超越标题，不能把放大文字作为默认填充法；图片只等比缩放或适当裁切并保留关键内容 |
| L3 结构 | 让内容形状与内容区匹配：宽区域尝试横向并排，长区域尝试纵向组织；按内容量分栏；同排可比卡片等高、标题顶部对齐、末项在既定底部区对齐 | 可以正式重选目录布局或更新自定义蓝图并重新编译；不能保留原合同却偷改固定模块尺寸、padding 或模板锚点。不为末项贴底拉出无功能的大间距 |
| L4 表达 | 用已有证据改为关键数字、真实引言、图标加标签或图表；有助解释时添加来源明确的图片/示意图。仅一个信息点时可用大字聚焦组织，并说明其预留空白用途 | 保持原意、证据和层级；不能补造文字或数据、引入未经支持的新结论。改为金句布局仍需真实内容及留白依据 |

**溢出单独处理**：从 L1 减间距、L2 在下限以上缩小尺寸、L3 调整结构、L4 合理拆成两个模块/页面依次尝试；每步复检。关键字不能被藏进微字或移出内容区，拆分后重新检查叙事、来源和当前蓝图。

## X — 禁止假修复

| ID | 禁止行为 |
|---|---|
| X1 | 偷改已选固定模块的尺寸或内边距。需要改变结构时走 L3，正式更新布局与蓝图。 |
| X2 | 移动模板固定标题、logo、页码或来源安全区来掩盖问题。 |
| X3 | 任意微调字号/间距以凑满。文字只用设计档位；弹性图形可在自身约束内连续调整尺寸。 |
| X4 | 打乱标题、小标题、正文、注释的层级或当前页面的焦点合同。 |
| X5 | 拉伸图片比例、将位图显示像素放大超过原始像素尺寸，或破坏图表比较量尺；裁切不得丢关键内容。 |
| X6 | 用字间距、词间距、空行、空框、重复结论、无意义图标或背景扩张伪造饱满。 |
| X7 | 为填空白添加原材料和有效证据中不存在的文字、数据或结论。 |
| X8 | 给同排、同语义角色文字用不同字号以弥补内容量差异；用合理内容分配、间距、弹性元素或布局解决。 |

## V — 复检与交付记录

1. **V1**：对本模块及同排所有模块重新执行 D1–D3；修改范围波及其他页面时一并复检。最终查看当前 HTML 与实际导出的 PDF，打印 DOM 记录不代替 PDF 画面。
2. **V2**：确认层级、阅读顺序、主辅关系与比较量尺未被填充修复改变；证据仍支持原主张。
3. **V3**：确认字号、行长、行高仍在所选设计系统的可读范围。行长按实际换行检查，不能按容器宽度猜测。

最终 `qualityChecks` 的 `module-fill` 单独成项。逐区域观察引用当前 HTML/PDF 证据；作者与适用的独立审查者分别记录自己的所见。自动枚举清单须核对并补充，量化预警须逐条处置。无设计功能的大块正文留白属于 Major，裁切按受影响内容分级；未解决 Major/Blocking 不通过，未查看的区域保持未验收。

使用 `review-pack` 生成的当前未审草稿，保留通用审查身份、状态及 `evidenceIds` 绑定，填写以下字段：

| 字段 | 填写要求 |
|---|---|
| `inventoryChecks` | 每个正文页一项 `{pageId, basis}`。依据实际 HTML/PDF 核对自动枚举是否覆盖完整正文、模块及每一栏，`basis` 写具体核对依据与补充区域，不能只写“完整”。 |
| `observations` | 每个已枚举的 `pageId + regionId + medium` 各一项，`medium` 为 `html` 或 `pdf`；填写 `observed`（实际所见）、`decision`（修复/保留判断）、`whitespace`、`diagnostics`。区域身份来自当前 audit，不可用父模块记录替代子栏或用 HTML 观察代替 PDF。 |
| `observations[].selector` | 自动枚举区域可保留草稿中的 selector，若提供必须与当前枚举一致。手动补充区域必须填 selector，见下文。 |
| `observations[].whitespace` | 每块保留空白用 `{position, function, basis}` 写位置、设计功能与依据；无保留空白用 `[]`。探针中每个 `reserved` 区域还须在这里用其 `selector` 一一对应，不可仅用一条泛化理由覆盖多处预留。 |
| `observations[].diagnostics` | 对当前区域 `findings` 每项用 `{index, disposition, basis}` 处置；`index` 是从 0 开始的原数组位置。未审草稿为 `not_reviewed`；完成审查后仅接受有依据的 `design-space` 或 `measurement-artifact`，不能直接写“已修好”保留旧诊断。 |

`design-space` 表示该位置确有阅读或设计功能，必须在 `whitespace` 中以相同 `position` 写明功能与依据。`measurement-artifact` 只用于已对照实际画面和测量边界确证的误报，须解释为什么探针判断不适用。**D3 裁切/溢出只能以确证的测量误报处置，不能以设计留白保留。真实缺陷须修复、重新生成 audit 和证据，确认对应缺陷消失后再填写当前审查。**

补充探针未识别的区域时，另用稳定且未占用的 `regionId`，设置 `manual: true` 与实际 `selector`，同一页的同一个手动区域必须分别填写 `html`、`pdf` 两条观察，并在 `inventoryChecks.basis` 说明。不能把已自动枚举的区域标为 manual 来绕开其诊断，也不能借手工记录省略自动区域。

人工记录可读示例：`Slide 07 | 右侧文字模块 / 第二栏 | HTML + PDF | D1/D2 | 默认样式基线未测量；成稿下方连续空白 142px | 下 | 无阅读功能 → L3 改为两组横排 | 同排复检完成`。具体文件格式使用当前审查草稿，不把示例中的数字当默认值。

## 默认诊断参考与项目档位

| 项目 | 使用方式 |
|---|---|
| 默认样式填充率 85% / 60% | 仅在真实基线可得时用于规划与修复分流；不是自动视觉通过线 |
| 同行填充率差 ≤15 个百分点 | 仅比较同功能、同排且默认样式可比的模块 |
| 最大组间距 | 当前设计系统的默认组间距 ×2；横纵分别以该轴的有效默认间距为准。模板指定上限更严时服从模板 |
| 字号候选范围 | 默认字号 −1 档至 +2 档，且始终受全局层级、页面可读下限与选定组件上限限制；没有这些档位就不可用 |
| 正文行高与行长 | 1.4–1.8、中文 20–40 字或英文 45–75 字符是连续正文的检查参考；采用已选设计系统并记录偏离原因。短标签、图表注释、卡片标题不机械套正文行长 |

目录模块的默认容量、实际字号与行高以 [单页系统](consulting-page-system.md#容量选布局时就知道装不装得下)、所选样式及运行时合同为准；不要为套用本表覆盖既有排印合同。
